# Električar Beograd – sajt

Statička stranica (HTML/CSS/JS, bez build koraka). Otvorite `index.html` u pregledaču.

- `index.html` – sadržaj stranice
- `css/style.css` – stilovi (boje su definisane kao CSS promenljive u `:root`)
- `js/main.js` – meni, slider usluga, tabovi, FAQ
